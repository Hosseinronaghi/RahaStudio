# Raha Studio Android

GitHub-ready Flutter project with a real FFmpeg audio engine.

## Implemented
- Decode audio and video audio tracks
- Encode MP3, WAV, M4A and FLAC
- FFT noise reduction
- Speech EQ
- Compressor
- Hum reduction
- Loudness normalization
- Leading/trailing silence trimming
- Progress and cancellation

## GitHub build
The workflow at `.github/workflows/android-build.yml` builds APK and AAB files automatically.

Open:

**Actions → Build Raha Studio Android → Artifacts**

Persian instructions are in `GITHUB_BUILD_FA.md`.
